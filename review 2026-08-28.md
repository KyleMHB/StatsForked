# Stats Forked documentation audit

Review date: 2026-08-28  
Scope: `README.md` and `steam-description.md` compared with the current working tree, published Workshop metadata, and the global README and Steam templates in `E:\Coding\Templates`.

## Executive verdict

The Steam description is structurally sound and mostly matches the current implementation, but it contains two concrete UI inaccuracies and one template-policy omission. The README is materially stale: it sends users to the removed original Workshop item, advertises a removed Odyssey table, omits the latest user-facing features, and gives a manual-install sequence that cannot work from a fresh clone without first building the mod.

The core feature descriptions are otherwise well supported by the code. The documented Debug build succeeds for Core, Biotech, Anomaly, Combat Extended, and Odyssey. RimWorld 1.6 remains the current official release line as of this review.

Recommended publication decision: correct the High and Medium findings before treating either document as release-ready. The safest first batch is documentation-only and does not require a version bump.

## Findings

### DOC-001: README links Stats Forked to the removed original Workshop item

**Severity:** High  
**Confidence:** High  
**Affected material:** `README.md:26`, `README.md:108`

The README labels item `3479566439` as the Stats Forked page. Steam identifies that item as the original `Stats` mod by Azkiy and reports that it has been removed from public Community visibility. The current fork item is `3712317437` and is also recorded in `About/PublishedFileId.txt`. The Steam draft correctly labels `3479566439` as the original mod.

**Impact:** The primary installation link sends users to the wrong and removed item.

**Recommendation:** Replace both README Workshop URLs with `https://steamcommunity.com/sharedfiles/filedetails/?id=3712317437`. Keep `3479566439` only as an explicitly labeled upstream-history link if it remains useful.

**Verification:** Open both README links while signed out and confirm the page title is `Stats Forked`.

### DOC-002: README manual installation cannot work from a fresh clone as written

**Severity:** High  
**Confidence:** High  
**Affected material:** `README.md:32-35`

The README says to download or clone the repository and place it directly in RimWorld's `Mods` directory. Compiled assemblies and `Runtime Only` are ignored and are not tracked, so a fresh clone contains source and definitions but no loadable mod DLLs. GitHub also currently has no published release artifact.

**Impact:** Manual-install users can follow every listed step and still get a nonfunctional mod.

**Recommendation:** Split manual installation into two evidence-backed paths: download a packaged release when one exists, or build the solution and copy `Runtime Only/Stats Forked` after a successful build. Do not present a raw clone as a ready-to-load package.

**Verification:** Test the instructions from a clean clone with no pre-existing `Assemblies` or `Runtime Only` directories.

### DOC-003: README advertises a removed Odyssey fishing-outcomes table

**Severity:** Medium  
**Confidence:** High  
**Affected material:** `README.md:17`, `README.md:49`, `README.md:67`

The README lists fishing outcomes three times. `CHANGELOG.md:51` records that the table was removed, and `Odyssey/Defs/Tables_Odyssey.xml` defines only books, fish, gravship systems, orbital infrastructure, and unique weapons. Fishing-outcome worker and column files remain packaged but are unreachable because no TableDef exposes them.

**Impact:** Users expect a table that is not available in-game, while dead packaged material makes the repository look internally inconsistent.

**Recommendation:** Remove fishing outcomes from the README. Separately decide whether to delete the dead code/XML or restore the table, but do not advertise it until it is reachable.

**Verification:** Confirm the five Odyssey TableDefs and check the in-game table picker with Odyssey active.

### DOC-004: Steam describes the expanded view as a fixed three-line mode

**Severity:** Medium  
**Confidence:** High  
**Affected material:** `steam-description.md:16`

Current code sets `MultiValueDisplay.MaxLines` to 10 and computes row height from the largest expandable cell in each row. It is neither fixed-height nor limited to three lines.

**Impact:** The description understates and mischaracterizes a visible feature that was just changed.

**Recommendation:** Describe it as an optional expanded view with adaptive rows up to ten lines, with complete values retained in tooltips.

**Verification:** Open a table containing cells with two, four, and more than ten values and compare row heights.

### DOC-005: Steam uses the wrong button name

**Severity:** Medium  
**Confidence:** High  
**Affected material:** `steam-description.md:24`

The instructions say to use the `Expanded` button. The shipped English key `StatsForked_Values` renders as `Expanded View`.

**Impact:** Players looking for the named control will not see an exact match.

**Recommendation:** Use the exact label `Expanded View`.

**Verification:** Confirm the localized toolbar label in English after startup.

### DOC-006: Steam implies the Mod Settings screen controls table behavior

**Severity:** Medium  
**Confidence:** High  
**Affected material:** `steam-description.md:38`

`StatsMod` exposes a settings category and persisted data but does not override `DoSettingsWindowContents`. Presets, filters, columns, variants, and expanded view are controlled in the table UI, not through a functional Mod Settings panel.

**Impact:** Users may open Mod Settings and find no controls matching the instructions.

**Recommendation:** Say that these choices are configured in the table UI and stored in RimWorld's global mod-settings data.

**Verification:** Inspect the Mod Settings page and exercise each control from the Stats table.

### DOC-007: README is incomplete for the current feature set

**Severity:** Medium  
**Confidence:** High  
**Affected material:** README Features, Usage, and Configuration sections

The Steam draft and current code include default presets, restored open tables and active table, hidden-column filters, expanded multi-value view, and translated toolbar/filter text. The README omits all five. Its preset list also omits the expanded-view state now stored in each `TablePreset`.

**Impact:** GitHub readers receive an older and less useful picture of the fork than Workshop readers.

**Recommendation:** Add concise, implementation-backed bullets and update Configuration to distinguish global session state from per-preset state.

**Verification:** Map every added sentence to `StatsSettings`, `MainTabWindow`, the preset code, or the filter code.

### DOC-008: “General stats” is presented as a table category that does not exist

**Severity:** Low  
**Confidence:** High  
**Affected material:** `README.md:9`, `steam-description.md:8`

Core defines table categories for ranged and melee weapons, apparel, several building types, plants, animals, mechanoids, turrets, and bionics. There is no General Stats TableDef. `Columns_Stats.xml` supplies general-purpose columns such as colony-owned and map-visible state.

**Impact:** The wording is mildly misleading.

**Recommendation:** Replace `and general stats` with a precise category list, or say that tables include general-purpose stat columns.

**Verification:** Enumerate all `Stats.TableDef` entries in the loaded Defs.

### DOC-009: Steam's forking policy omits the template's non-binding clarification

**Severity:** Low  
**Confidence:** High  
**Affected material:** `steam-description.md:47-50`

The global Steam template requires the policy to be identified as a request rather than an added license restriction. The current wording says the maintainer reserves the right to request contributions, but does not explicitly make the non-binding status clear.

**Impact:** The policy can be read as a license condition despite the inherited LGPL terms.

**Recommendation:** Add one short sentence: `This is a project request, not an additional license restriction.`

**Verification:** Recheck the License and Forking Policy section against `Steam/steam-description-template.md`.

### DOC-010: About metadata contains a dead repository URL

**Severity:** Medium  
**Confidence:** High  
**Affected material:** `About/About.xml:7`

The README and Steam draft use the confirmed canonical repository `KyleMHB/StatsForked`. `About.xml` uses `KyleMHB/Stats-Forked`, and `git ls-remote` reports that repository as not found.

**Impact:** RimWorld's mod metadata can direct users to a dead page even after the two publication documents are fixed.

**Recommendation:** Change the metadata URL to `https://github.com/KyleMHB/StatsForked` in the same documentation-only batch.

**Verification:** Resolve the URL without relying on an authenticated GitHub session.

### DOC-011: Upstream attribution uses a noncanonical spelling

**Severity:** Informational  
**Confidence:** High

Both documents display `AzzkiyOne`, while the canonical GitHub account and upstream remote are `AzkiyOne`. GitHub currently redirects the old spelling, so the links work, but attribution should use the maintainer's canonical name.

**Recommendation:** Normalize visible names and URLs to `AzkiyOne`; retain `Azkiy` where referring to the Steam display name.
