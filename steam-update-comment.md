Stats Forked has been updated for the latest maintenance and compatibility fixes.

Changes:
- Compatibility assemblies now use unique filenames, avoiding collisions with other Stats-based mods.
- Combat Extended column tags and optional-module loading have been tightened up.
- Table windows now restore their open tables, order, active tab, and saved default presets.
- Column filters can remain active while their source column is hidden.
- Window resizing is stable, and expanded multi-value cells use a fixed three-line row height.
- More table, filter, and help text is ready for translation.

Important: fully restart RimWorld after updating. The optional compatibility assembly filenames changed, and a complete restart is required for the new files to load correctly.

Item 8 (the materials/textiles/leathers table) is not included in this update.
